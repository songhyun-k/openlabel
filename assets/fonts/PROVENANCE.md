# 포함 글꼴

NanumGothic-Regular.ttf와 OFL.txt는 Google Fonts 저장소의
[5e35378e6bda803962ee6fd257e444a7d459660d](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/nanumgothic)에서
2026-09-05에 받은 원본이다. SIL Open Font License 1.1을 함께 배포한다.

- TTF SHA-256: `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31`
- OFL SHA-256: `eeacf16032901d0ed0456876ec77b8f0fda6b3fecec7d972f8543eb602e6c30f`
- 실제 TTF family: `NanumGothic` / `나눔고딕`. SVG의 `Nanum Gothic`,
  `NanumGothic`, `sans-serif`는 같은 포함 글꼴 하나를 사용한다.
- OS 글꼴 검색·외부 글꼴 다운로드는 하지 않는다. Regular 한 가지이며
  다른 글꼴 파일이나 별도 bold/italic face는 포함하지 않는다.
